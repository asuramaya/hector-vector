## Phase 1 — Quick-win bugs

1. **Pipeline upscale reads `src` not `current`** (`server.py:2958-2969`,
   HIGH, hand-verified). The De-JPEG/denoise/deblur prelude advances
   `current`; all three upscale branches read `src`, silently discarding the
   restoration output. One-word fix ×3 (incl. the alpha check).
2. **`confirmDialog` never resolves on backdrop/Close** (`app.js:858-899`,
   HIGH, hand-verified). Generic modal closers call `closeModal()` without
   settling the promise; `serializeForSave` awaits it → **saves hang
   silently**. Route all close paths through an on-close hook.
3. **Jobs "View" is a no-op while pinned** (`app.js:4632`, MEDIUM). Boot/New/
   Open set `editor.pinned`; `renderPreviews` bails when pinned. Clear pinned
   in `viewJobOutput` like the poller auto-land does.
4. **WYSIWYG fast path drops restoration stages** (`app.js:4504`, MEDIUM).
   The vectorize short-circuit checks upscale/removebg but not
   dejpeg/denoise/deblur. Require vectorize to be the *only* enabled stage.
5. **`inputs.hex` ReferenceError** (`app.js:1232`) + **dead `toolsTitle`
   Settings deep-link** (`app.js:1883`, swallowed by try/catch). Trivial.
6. **Zoom buttons bypass the 0.02–40 clamp** (`app.js:815`). Route through
   `zoomVp`.
7. **Non-file drops navigate the app away** (`app.js:4368-4383`), destroying
   the unsaved canvas. Always preventDefault at window level.
8. **Compound-path corruption stopgap** (`shapes.js:225` / `path.js:137`,
   HIGH). `pathToAnchors`→`penPathD` fuses all subpaths into one; seven
   structural-edit call sites corrupt boolean results / traced art. Stopgap:
   refuse structural edits when `d` has >1 `M`. Proper fix is Phase 4.
9. **simplify_svg silently corrupts non-vtracer paths**
   (`tools/simplify_svg.py:23-65,319`, MEDIUM). Relative coords treated as
   absolute, H/V/S/Q/T/A dropped, and the regex rewrites every `d=` incl.
   clipPaths. Add a vocabulary bail-out + restrict to `<path>`.
10. **Localhost CSRF** (`server.py` `do_POST`, MEDIUM-HIGH locally). No
    Origin/Host check: any web page can POST to :2002 — repoint the source
    dir at `~`, delete/upload files there, trigger `git pull`+`pip install`.
    One Origin allowlist check closes it. (Path traversal was audited: clean.)
11. **face_restore detects at native res, detect_faces at 1024**
    (`face_restore.py:59` vs `detect_faces.py:27`, MEDIUM). Analyzer offers
    face restore on big photos; restore then finds 0 faces and no-ops. Share
    the detection scale.
12. **Cleanup mask likely 1×1** (`app.js:5370` via `mediaNaturalSize:481`,
    HIGH for the feature — needs live repro first). SVG `<image>` has no
    naturalWidth and clientWidth 0 → mask canvas POSTed to /api/cleanup is
    1×1; painted region can't map to the source.

## Phase 2 — Server hardening

13. **Guarded job runner** (`server.py:1230-1276`, HIGH). Non-FileNotFound
    exceptions (e.g. UnicodeDecodeError on non-UTF-8 subprocess output) kill
    the runner thread for `immediate=True` jobs with **no except clause**:
    job stuck "running" forever, zombie child, and `_has_active_jobs()` true
    forever → **auto-spindown permanently disabled** (the stale-server class
    of bug again). One `_run_guarded()` wrapper; `errors="replace"` on
    stdout; deep-copy jobs under the lock for `/api/jobs` (`:3552`).
14. **Watchdog vs synchronous ops** (`:243` vs `:2400/:1782/:1857/:1872/
    :2853`). Raster ops / inpaint / face restore / trace previews (incl. the
    928 MB rembg first-use download) have no job record; closing the window
    spins the server down mid-operation. Add an `_inflight` counter the
    watchdog consults.
15. **Atomic model downloads** (`:1660/:1742/:1767/:1811`). `curl -sL`
    without `--fail` caches HTML error pages as models; interrupted downloads
    skip the cleanup guard. One flaky download bricks a capability until the
    user hand-deletes a cache file. `fetch_model()`: `curl -fSL` → `.part` →
    size check vs `size_mb` → atomic rename.
16. **Polish batch**: POST errors all map to 400 (`:3705`); `serve_file` on a
    directory crashes the handler (`:3734`); preprocess-cache eviction can
    unlink a file mid-trace (`:721`); unbounded request bodies + short-read
    truncation (`:3633/:3223`); `reveal_path` zombies (`:3493`).

    sub-0.4° rotations persist un-undoably (no orig restore, unlike scale);
    crossing the threshold snapshots an already-rotated doc → undo drift.
